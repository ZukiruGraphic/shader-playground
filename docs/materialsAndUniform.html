📦 Custom 3D Textures (Global)

All custom textures added in the 3D Textures & Uniforms menu (e.g., uTextureExtra0) are automatically registered and ready to use across all 3D shaders below:

1. Cube Material (shaders/cube.*)

Uniforms: sampler2D uTexture, vec2 uUvScale, vec3 uDirLightPos, vec3 uDirLightColor, vec3 uAmbientColor, vec3 uCameraPosition, vec3 uSpecularColor, float uSpecularPower, float uSpecularIntensity, float uAOStrength, vec3 uFogColor, float uFogNear, float uFogFar, plus all custom 3D textures.

2. Ground Material (shaders/ground.*)

Uniforms: Identical to the Cube Material. Supports per-vertex aAO (Ambient Occlusion) modulation.

3. Post-Processing Material (shaders/post.*)

Uniforms: sampler2D tDiffuse, sampler2D tDepth, sampler2D tNormal, float uCameraNear, float uCameraFar, float uVignetteIntensity, float uVignetteRoundness, vec3 uSunPosition, vec3 uDirLightPos, vec3 uCameraPosition, plus all custom 3D textures.

4. Sky Material (shaders/sky.*)

Uniforms: vec3 uSunPosition, plus all custom 3D textures.

5. Normal Material (Internal Buffer)

Used to render absolute World Normals (X=Red, Y=Green, Z=Blue) into the tNormal render target. Calculates static mat3(modelMatrix) * normal.

6. 2D Canvas Material (shaders/canvas.*)

Uniforms: float uTime, vec2 uResolution, plus custom 2D textures (uTexture0, uTexture1, etc.).
